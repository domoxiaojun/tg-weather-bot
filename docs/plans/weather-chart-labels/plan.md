## 已锁定规则

- 默认/逐小时：当前下雨或下雪，或未来 24 小时出现雨雪、降水概率至少 50%、降水值大于 0 时发降水图；否则发逐小时温度图。
- 逐日固定发逐日温度图，降水固定发降水图，生活指数不自动附图。
- 降水数字只标概率至少 30% 或降水值大于 0 的时段；缺失值不当作 0。
- 降水累计量显示 `mm`，降水强度显示 `mm/h`。
- 所有自动附图失败均回退到原有文字/富文本天气，不让查询失败。
