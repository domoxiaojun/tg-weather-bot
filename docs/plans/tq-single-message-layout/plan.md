## 验收约束

- `/tq` 在富消息可用时只产生一条用户可见消息，图表渲染或富消息失败时只降级为一条完整文字天气。
- 生活指数位于天气详情之后、空气质量之前，不进入天气详情表或任何天气图。
- Telegram Rich Text 不支持自定义正文颜色；预警使用警示图标与粗体表达，不使用 `marked` 背景。
